# Methodology

## Environment

The environment is a causal dynamical system with known underlying interactions.

## Agents

Each agent observes a different subset of variables.

```text
Agent A: subset of variables
Agent B: subset of variables
Agent C: subset of variables
```

## Communication

Agents produce symbolic messages from local trends and local state summaries.

## Evaluation

The experiment evaluates:

- local prediction error,
- shared model prediction error,
- message entropy,
- symbol usage,
- theory-of-mind-style prediction error.

## Interpretation

If message exchange improves shared predictive structure, the result supports the claim that communication can function as a mechanism for distributed world-model construction.
